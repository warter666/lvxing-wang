# 旅行汪 🐕

一个类似「旅行青蛙」但**不是游戏**的小工具：把出去玩的照片丢给汪，汪会按拍摄顺序把你的行程**模拟重演一遍**——照片逐站回放、配有趣旁白和汪叫音效。汪的设定是**不能说人话，只能汪汪叫**（人话由"旁白"代笔）。

## 怎么用

双击打开 `旅行汪.html` 就行（推荐 Edge / Chrome 浏览器），不需要安装任何东西。

1. **丢照片**：把出去玩的照片拖进上传区（可以多选）。
   - 照片里的 **EXIF 拍摄时间**会被读出来，汪按时间自动排序；
   - 照片里有 **GPS 定位**的话，汪会在地图上画出你的足迹路线。
2. **整理站点**：每一站可以改名、上下移动、删除。
3. **点「让汪出发」**：汪把行程模拟一遍——每站一张拍立得照片，汪小跑进场、汪汪叫、旁白打字机讲有趣的故事，自动播到下一站（也可以 ←/→ 手动切、空格暂停）。
4. **汪的游记**：播完后自动生成一篇图文游记，可以一键复制发给朋友。

## 其他功能

- 🎁 **示例旅行**：没照片也可以先看一遍效果（Canvas 画的示例图，杭州一日游）。
- 🗣 **汪语翻译器**：点了会被汪拒绝（汪把它啃坏了）。
- 🐶 给汪起名字、挑一只小狗形象、静音汪叫。
- 🧹 清空重来。

## 隐私

照片**只在你自己的浏览器里处理**，不会上传到任何服务器。站点数据（含压缩缩略图）存在浏览器 localStorage，大图只保留在当前页面内存里，刷新后回放会改用缩略图。

## 唯一的联网需求

地图瓦片（高德 → Carto → OpenStreetMap 依次回退）和 Leaflet 库走 CDN。断网时地图区域会显示文字版足迹，回放、游记等功能完全不受影响。
