# 旅行汪 🐕

一个类似「旅行青蛙」但**不是游戏**的小工具：把出去玩的照片丢给汪，汪会把你的行程**模拟重演一遍**——照片逐站回放、有趣旁白、汪叫音效。汪的设定是**不能说人话，只能汪汪叫**（人话由"旁白"代笔）。

**在线使用**：[warter666.github.io/lvxing-wang](https://warter666.github.io/lvxing-wang/) （数据只存在你自己的浏览器里）

## 它能干什么

- 🗺️ **卡通中国地图（主界面）**：手绘风省界色块 + 中文标注，可拖动、滚轮缩放。带定位的照片会变成**照片钉**钉在拍摄地，去过的省份会点亮橙色描边。地图上还散布着 36 个名胜图标，是汪的梦想清单——你真去了附近（40 公里内），那个图标就会点亮。
- 🎒 **行囊**：照片按 EXIF 拍摄时间自动排序，每站可改名、排序、删除；每站一张 **📇 玩法卡**。
- 📇 **玩法卡**（A 方向）：把小红书/马蜂窝看到的攻略**粘贴进来**（文字或链接），配了大模型就自动总结成「怎么玩 + 小故事」，没配也会存成摘录；回放时旁白会翻攻略给你听。
- 🎒 **行程回放**：汪把旅程走一遍——每站一张拍立得，汪小跑进场、冒汪语气泡、WebAudio 现场合成的汪叫，旁白打字机讲故事，自动播到下一站。
- 💭 **故地重游**：去过的地方自动按位置聚类（"断桥残雪 · 去过 5 次"），点开翻旧照片；还能以任意一站为圆心找附近回忆。
- 📖 **游记**：一键生成图文游记，可复制分享。
- ✨ **AI 叙事（可选）**：填一个 OpenAI 兼容接口（预设了智谱 glm-4-flash / DeepSeek / 通义），AI 会写玩法卡和现编旅行小故事。Key 只存你自己浏览器里。
- 🗣 **汪语翻译器**：点了会被汪拒绝（汪把它啃坏了）。

## 怎么用

打开网页（或本地双击 `index.html`）→ 丢照片 → 点「让汪出发」。照片**只在你的浏览器里处理**，不上传任何服务器；站点数据（含缩略图）存 localStorage，大图仅保留在当前页面内存里。

## 技术备注

- 单文件网页，无构建、无后端；省界数据（DataV.GeoAtlas 的中国 GeoJSON，简化后约 240KB）内嵌在页面里，**地图功能离线可用**。
- AI 总结走浏览器直连大模型接口；粘贴的是链接时会先尝试经 `r.jina.ai` 公共只读代理抓正文（小红书等强反爬站点可能失败，届时请粘贴文字）。
- 卡通地图仅为示意，**不用于导航**。

## 隐私

照片与数据全程留在本地浏览器。唯一的对外请求：可选的 AI 接口（你自己填的 key）、可选的链接正文抓取代理。
